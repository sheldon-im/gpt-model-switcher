# GPT Model Switcher

개인적으로 모델과 추론 수준을 용도에 맞게 조절할 수 있을까 하는 호기심에 만들어본 앱 입니다.

가볍게 물어볼 때와 조금 더 생각이 필요한 작업을 할 때, 원하는 조합을 단축키로 바꿀 수 있으면 좋을 것 같았습니다. 자주 쓰는 모델과 추론 수준을 미리 정해 두고, 필요할 때 한 번에 바꾸는 방식입니다.

ChatGPT 데스크톱 앱의 기존 로컬 Work 대화에서 사용합니다. 모델을 바꾸려고 메뉴를 열거나 작성 중인 입력창에서 이동할 필요가 없도록 만들었습니다. 바꾼 설정은 다음 메시지부터 적용됩니다.

## 일단 설치해서 써보기

[0.1.5 다운로드](https://github.com/sheldon-im/gpt-model-switcher/releases/tag/v0.1.5)에서 Mac용 파일을 받을 수 있습니다. **Apple Silicon Mac, macOS 13 이상**이 필요합니다. 현재 릴리스에 올린 설치 파일은 Mac용입니다.

1. `gpt-model-switcher-0.1.5-macos-arm64-test.dmg`를 받아 여십시오. ZIP이 편하시면 `gpt-model-switcher-0.1.5-macos-arm64.zip`을 받아 압축을 풀어도 됩니다.
2. 안에 있는 **GPT Model Switcher**를 응용 프로그램 폴더로 복사하십시오. Finder에서 앱을 선택하고 Command+C, Command+Shift+A, Command+V를 차례로 누르면 됩니다. 이전 버전이 실행 중이라면 먼저 메뉴 막대에서 **종료**를 선택해 주십시오.
3. 응용 프로그램 폴더에서 **GPT Model Switcher**를 실행하십시오. 설정 창이 바로 뜨지는 않고 메뉴 막대에 상주합니다.
4. 손쉬운 사용 권한을 요청하면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 **GPT Model Switcher**를 허용해 주십시오. 앱 설정의 **손쉬운 사용 권한 설정 열기** 버튼으로도 이동할 수 있습니다. VoiceOver에서는 해당 앱의 스위치를 찾아 VO+Space로 켜 주시면 됩니다.

Apple의 앱 공증은 받지 않은 버전이라 처음 열 때 macOS의 보안 확인이 표시될 수 있습니다. 앱을 새 버전으로 교체한 뒤에는 손쉬운 사용 권한을 다시 허용해야 할 수도 있습니다.

## 모델 바꾸기

ChatGPT에서 기존 로컬 대화를 열고, 답변이 끝난 상태에서 입력창에 포커스를 둔 뒤 아래 단축키를 누르십시오.

| 용도 | 모델 | 추론 수준 | Mac 단축키 |
| --- | --- | --- | --- |
| 일상용 | GPT-6.1 Terra | medium | Command+Option+Shift+1 |
| 코딩용 | GPT-6.1 Sol | high | Command+Option+Shift+2 |

이름은 일상용과 코딩용으로 붙였지만, 꼭 그 용도로만 쓸 필요는 없습니다. 설정에서 이름과 모델, 추론 수준, 단축키를 원하는 조합으로 바꿀 수 있습니다. 모델은 현재 계정에서 사용할 수 있는 것을 지정해 주십시오.

같은 조합이 이미 적용되어 있으면 다시 바꾸지 않고 현재 상태를 안내합니다. 답변을 만드는 중이거나 대상 대화를 확인할 수 없으면 전환을 멈춥니다. 새 대화, 클라우드·원격 대화 등은 지원 범위가 제한됩니다.

## 설정을 바꾸고 싶을 때

메뉴 막대의 **GPT Model Switcher → 설정 / Settings**를 여십시오. Tab과 Shift+Tab으로 항목을 이동하고, 편집을 마치면 **저장**을 눌러 주시면 됩니다.

- 자주 쓰는 모델·추론 수준과 단축키를 바꿀 수 있습니다. 모델 항목에는 `gpt-6.1-terra`처럼 모델 ID를 입력합니다.
- 화면 알림과 스크린 리더 안내를 각각 켜거나 끌 수 있습니다. Mac에서는 화면 알림이 기본으로 꺼져 있습니다.
- **음성 안내 시험**으로 모델을 바꾸지 않고 안내만 들어볼 수 있습니다. 안내 설정을 바꿨다면 먼저 저장해 주십시오.
- **최근 전환 결과**에서 이번 실행 중 어떤 전환이 있었는지 확인할 수 있습니다.

설정 창을 닫아도 앱은 계속 실행됩니다. 완전히 끝내려면 메뉴 막대에서 **종료 / Quit**를 선택하십시오. 로그인할 때 자동으로 실행되도록 등록하지는 않습니다.

## 사용하면서 알아둘 점

Mac용 0.1.5는 앱 빌드와 자동 검사를 마쳤고, VoiceOver를 사용하는 환경에서도 동작을 확인했습니다. 점자와 작성 중인 문장·선택 영역·커서 보존 등 세부 항목의 확인 범위는 [릴리스에 첨부한 검증 기록](https://github.com/sheldon-im/gpt-model-switcher/releases/download/v0.1.5/MAC_VERIFICATION-0.1.5.json)에 따로 남겼습니다.

ChatGPT 앱의 내부 연결을 사용하므로 ChatGPT가 업데이트되면 동작이 달라질 수 있습니다. 전환이 되지 않을 때는 설정의 최근 결과와 권한 상태를 먼저 확인해 주십시오. OpenAI의 공식 앱이나 공식 확장 기능은 아닙니다.

Windows 11 x64용 소스도 함께 들어 있습니다. Windows의 기본 단축키는 Ctrl+Alt+Shift+1과 Ctrl+Alt+Shift+2입니다. 직접 빌드하려면 [빌드 안내](docs/BUILD.md)를 참고하십시오.
