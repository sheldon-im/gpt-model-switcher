# 구성요소별 커밋

## 0.1.2 이미 적용된 프리셋 처리

① 실제 모델·추론을 다시 읽어 ‘이미 적용됨’ 결과를 구분하고 쓰기/포커스 조작을 생략하는 처리와 회귀 검사, ② 음성·화면·최근 결과의 한국어/영어 안내 및 표시 검사, ③ 시험판 버전·패키지·Mac 인계 지침 갱신의 3개 구성요소로 나눕니다. 사용자에게 시험 안내가 한 번 들렸다는 회신을 받은 것은 0.1.1 단일 안내의 사용자 검증이며, 모든 프리셋/점자/Mac 검증을 뜻하지 않습니다. 후속 구성요소를 먼저 역순으로 되돌리며 전환 코어의 결과 필드를 제거할 때 이를 소비하는 안내도 함께 되돌립니다.

## 0.1.1 음성 피드백 복구

사용자는 포커스 문제는 나아졌으나 프리셋 변경 결과의 음성이 사라졌다고 직접 보고했습니다. 이 회귀는 ① NVDA 공식 controller 전송과 의존 자료·전송 회귀 검사, ② 최종 결과 연결과 모델을 바꾸지 않는 안내 시험 UI·중복 방지 검사, ③ 버전 갱신·패키지/문서·실행 교체의 3개 구성요소로 나눕니다. ②는 ①에 의존하며 되돌릴 때는 역순으로 진행합니다. ①만 되돌리면 이를 호출하는 ②도 함께 되돌려야 합니다. 포커스 없는 모델 전환 경로는 유지합니다. 실제 청취 확인과 API 요청 수락은 별도로 기록합니다.

## 포커스를 보존하는 전환으로 변경

실제 NVDA 사용 중 메뉴 조작의 중간 포커스·읽기 문제가 확인되어 기본 메뉴 자동화를 교체합니다. 이 기능은 ① 읽기 전용 대화 식별·프레임 프로토콜(정확·고유 제목, 크기 제한 검증), ② 두 설정의 조건부 일괄 적용·화면/포커스 검증(가짜 응답·변경된 문맥·복구 검사), ③ 포커스 없는 결과 표시·접근성 안내로 나눕니다. 내부 데스크톱 프로토콜은 비공개 호환 경로이므로 실패하면 중단하며 메뉴 조작으로 자동 대체하지 않습니다. ②는 ①에 의존합니다. 되돌릴 때는 ③→②→① 순서로 되돌리며, 메뉴 자동화의 NVDA 문제도 다시 나타나므로 이전 버전을 실사용 후보로 표시하지 않습니다.

각 기능은 저장·편집·단축키, 읽기·전환·활성화, 표시·접근성·패키징처럼 3개의 의미 있는 구성요소로 나눕니다. 커밋마다 구현과 해당 검증을 함께 포함합니다. 후속 구성요소는 앞선 인터페이스에 의존하므로 되돌릴 때는 의존하는 후속 커밋부터 역순으로 되돌립니다. 각 커밋 상태는 빌드 가능한 완결 상태를 유지합니다.

| 구성요소 | 완료 기준 | 되돌림 영향 |
|---|---|---|
| 프리셋 저장·읽기 | 기본값·파일 보존·검증 검사 통과 | 설정 저장 기능 제거; 사용자 설정은 삭제하지 않음 |
| 프리셋 편집 화면 | 키보드로 목록·편집·저장 가능 | 공통 코어 유지, 편집 UI 제거 |
| 단축키 편집·충돌 | OS별 입력과 충돌 검사 | 프리셋 편집 유지, 단축키 기능 제거 |
| 각 OS 읽기 | 대상 식별·상태·생성 중 감지 | 해당 OS 검사 기능 제거 |
| 각 OS 전환 | 실제 선택값 검증·부분실패 처리 | 해당 OS 전환만 제거 |
| 각 OS 활성화 | 활성 창 제한·중복 방지·포커스 복귀 | 자동 단축키 전환 비활성화 |
| 화면 결과 | 최근 성공·실패 결과 확인 | 결과 UI 제거 |
| 접근성 결과 | 화면 안내와 SR 안내 경로 | SR 안내 제거 |
| 시험 패키지 | 실행 파일·소스·Mac 인계 지침 | 산출물 생성 기능 제거 |

## 구현 이력과 현재 후보

프리셋은 저장·편집·단축키의 3개 커밋, 플랫폼 전환은 읽기·적용·활성화/포커스의 경계로 구현했습니다. 이후 실제 NVDA 관찰로 메뉴 방식이 부적합하다고 판정하여 읽기 연결(`c604405`) → 조건부 쌍 전환(`9ca50fa`) → 포커스 없는 결과/안내(`c04b8a5`, `3bc5496`)로 교체했습니다. `400bbaa`는 실제 연결 검증에서 발견한 Windows idle pipe 읽기와 로컬 화면 검증을 보강한 회귀 수정입니다.

현재 알림/시험 배포 기능은 ① 화면·최근 결과, ② 최종 1회 접근성 안내, ③ 플랫폼별 시험 패키지·빌드/검증/인계 문서의 3개 구성요소입니다. 패키징 커밋을 되돌려도 소스 전환 기능은 유지되고, 안내 커밋을 되돌리면 실제 SR 안내가 제거됩니다. 사용자 설정 파일이나 실제 앱 선택값을 Git 되돌림으로 삭제/변경하지 않습니다.
