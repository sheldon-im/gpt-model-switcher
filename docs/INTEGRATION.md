# Windows / Mac 소스 통합

사용자 지정 Mac 원본은 `Z:\Documents\Codex\sources\gpt-model-switcher`입니다. 원본 작업 폴더와 Git 이력을 수정하지 않고 Git bundle로 읽어 Windows에 가져왔습니다. 조회 당시 작업 트리는 깨끗했습니다. 공유 드라이브의 소유권 예외는 각 Git 조회 명령에만 적용했으며 글로벌 `safe.directory`는 변경하지 않았습니다.

- Windows 기준: `6fcae87ae8059f4b04d932187fe224fd63a278e8` (0.1.2).
- Mac 원본: `9007544` (0.1.4), 초기 보존 커밋 `56c9080`.
- 공통 파일 기준: Windows `658ff4ba368a5b0e141dcd1d98f1d24d86df3d88` (0.1.0). Mac 초기 커밋과의 차이는 `SOURCE_SNAPSHOT.json` 한 파일뿐임을 Git으로 확인했습니다.

## 구성요소와 되돌림

1. Mac 앱 내부 Swift AX 브리지·소켓 PID/권한·표준 모델 캐시·빌드/합성 검사 도구를 통합합니다. Windows의 NVDA 리소스 빌드와 이미 적용된 프리셋 결과 필드는 유지합니다. 이 구성요소를 되돌리면 Mac 네이티브 연결/모델 캐시 보완이 제거됩니다.
2. 권한 요청 UI, 실행 요청 구분, 조용한 Mac 시작·필요할 때만 결과 창 생성, 상주 앱 진단을 통합합니다. Windows NVDA 전송과 동일 프리셋 안내를 보존하며 관련 전경·설정·화면 검사를 수행합니다. 이 구성요소는 1에 의존하므로 먼저 되돌립니다.
3. 통합 버전·양쪽 검증 기록·Mac 인계·시험 패키지와 저장소 동기화 지침을 정리합니다. Mac 원본을 통째로 덮어쓰기 하지 않으며 원본 커밋은 별도 브랜치로 보존합니다.

Mac의 기존 결과는 `docs/MAC_VERIFICATION.md`의 Mac 작업자 기록 및 그 기록에 포함된 사용자 보고입니다. 이 Windows 작업에서 Mac 빌드나 VoiceOver를 재검증한 결과가 아닙니다. 통합 후 Mac 바이너리는 Mac에서 다시 빌드·시험해야 합니다. 원본 0.1.4의 사용자 전환 성공 보고를 통합본 전체 성공으로 확대하지 않습니다.
