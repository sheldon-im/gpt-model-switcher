## 실제 앱과 접근성 검증 경계

Swift 도우미 컴파일은 성공했습니다. 도우미의 `inspect`는 접근성 권한 필요 오류를 반환했습니다. 현재 도우미에서 활성 대화·모델 버튼·입력 포커스·생성 상태를 읽지 못했으므로 실제 설정 읽기/전환으로 진행하지 않았습니다. 다른 실행 파일로 권한을 우회하거나 TCC를 수정하지 않았습니다.

아래 항목은 모두 **미시험**입니다.

- 사용자 지정 기존 대화에서 Terra medium / Sol high 양방향 전환과 원래 설정 복구.
- 실제 작성문·선택 영역·커서 보존, 두 창·동일 제목·클라우드/원격 대화·생성 중 상태의 실기 차단.

접근성 권한은 사용자가 시스템 설정에서 직접 부여해야 합니다. 이 결과는 Windows의 NVDA 실패가 Mac에서 해결되었다는 판정이 아닙니다. 실제 프롬프트 전송·정식 서명·공증·공개 배포·자동 시작 등록은 수행하지 않습니다.
